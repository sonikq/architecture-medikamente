## Данные для защиты
| Тип данных                                        | Метод защиты                                             | Подходящие методы анонимизации                |
|---------------------------------------------------|----------------------------------------------------------|-----------------------------------------------|
| Персональные данные пациентов (PII)               | Шифрование (для хранения и передачи)                     | • Псевдонимизация<br>• Маскирование данных    |
| Медицинские данные и результаты анализов (PHI)    | Обезличивание (для аналитики и исследований)             | • Удаление идентификаторов<br>• Генерализация |
| Финансовые данные пациентов (PFI)                 | Шифрование + контроль доступа                            | • Маскирование<br>• Псевдонимизация           |
| SEN - Учетные записи сотрудников (логины, пароли) | Многофакторная аутентификация (MFA), хеширование паролей | • Псевдонимизация                             |
| TEM - Метаданные (время приема, назначения)       | Обезличивание данных                                     | • Псевдонимизация<br>• Маскирование данных    |

## Инструменты

* Шифрование файлов: BitLocker, EFS
* Шифрование баз данных: TDE, pgcrypto
* Защита передачи данных: TLS 1.3, HTTPS, SFTP
* Управление доступом (RBAC/ABAC): Keycloak, Azure AD
* Аудит доступа: SIEM (ELK, Wazuh), Auditd, Microsoft Sentinel
* Тегирование данных: Apache Atlas, Varonis
* Обезличивание и маскирование: Faker, DataMasker
* Защита API: OAuth 2.0, JWT, ограничение скорости запросов (Rate limiting)
* Контроль экспорта данных: DLP-системы (SearchInform, Solar Dozor DLP, Symantec)
* Разделение доступа по ролям: группы Active Directory, группы Keycloak, ограничения на уровне файловых систем
